# Model artifacts

These files are generated by `scripts/train_models.py`:

- `aqi_models.joblib` — the trained scikit-learn pipelines plus feature order,
  input ranges, target statistics, random-split and time-based evaluation
  metrics, signed residual quantiles for prediction intervals, scikit-learn
  version, and a SHA-256 hash of the training CSV.
- `metadata.json` — a human-readable copy of the training summary.

`feature_ablation.json` is generated separately by
`scripts/feature_ablation.py`. It records feature-set and imputation
experiments and does not change the app bundle.

Do not edit these files by hand. Regenerate them after changing the dataset or
any preprocessing step:

```bash
python scripts/clean_data.py       # rebuild Data/city_day.csv
python scripts/train_models.py     # retrain and rewrite the bundle
python scripts/feature_ablation.py # optional evaluation experiment
```

The app loads `aqi_models.joblib` through `aqi_app/models.py` and refuses to
run if the saved feature order does not match the app's feature definition.
The bundle is trained on the cleaned CSV and stores its SHA-256 hash, so a
stale bundle can be detected and regenerated.
